# My To-Do App

My first coding project — a to-do list web app built entirely from a phone.

**What it does:** add tasks, tap a task to mark it done, tap \u00d7 to delete it. Tasks are saved in the browser, so they're still there after closing the page.

**How it works:**

- `index.html` — the structure of the page
- `style.css` — the visual styling
- `script.js` — the behavior (adding, completing, deleting, saving)

Built with plain HTML, CSS, and JavaScript — no frameworks, no installation.
